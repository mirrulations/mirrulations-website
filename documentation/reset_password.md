1. Log on to the AWS Console: AWS Console

    In the search bar, type: Cognito and select it.

2. Go to the user pool: mirrulations_user_pool and select it.
3. In the user pool, select Users, under User Management on the side bar.
4. Click on whatever username you want to change the password for.
5. On the top right under Actions it says reset password
    
    It should prompt you with a pop click "Reset"
6. You should recieve an email with the code.
7. At the moment there is no space to add the code but as an alternative you can delete the user and follow the steps in documentation/Create A Mirrulations Account.
